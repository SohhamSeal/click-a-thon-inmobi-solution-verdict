Verdict: Complete Learning Guide

From ad events to root cause, explained in plain English with real hackathon examples.

Verdict is an automated investigator for ad tech metrics. When fill rate, CTR, or revenue moves, it finds which segment caused the move, proves the claim with counterfactual tests, and publishes what it ruled out. The numbers decide everything. A language model only writes the summary prose.

How to use this guide: Read in order if you are new. Each page starts with a simple story, then goes deeper into the technical details. Real incidents from the ClickHouse Click a thon 2026 dataset are used throughout.

Quick glossary

TermPlain meaning
segmentA slice of traffic, like "region = APAC" or "os_version = Android 15"
latticeAll 1 way and 2 way segment combinations we pre compute and scan
rollupPre summed counters (requests, fills, etc.) grouped by time bucket and segment
baselineWhat we expected based on the same segment's past weeks
findingA segment whose metric moved more than normal variation explains
caseA published verdict with evidence, confidence, narrative, and trace
passengerA segment that moved because a parent segment moved, not because it broke on its own
